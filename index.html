نمونه کد ۱ — ماشین حساب ساده

این مثال ورودی می‌گیرد، بر اساس عملگر تصمیم می‌گیرد و نتیجه را چاپ می‌کند. کد را خودت تایپ و اجرا کن.

num1 = float(input("عدد اول: "))
operator = input("عملگر (+ - * /): ")
num2 = float(input("عدد دوم: "))

if operator == "+":
    result = num1 + num2
elif operator == "-":
    result = num1 - num2
elif operator == "*":
    result = num1 * num2
elif operator == "/" and num2 != 0:
    result = num1 / num2
else:
    result = "عملگر نامعتبر یا تقسیم بر صفر"

print("نتیجه:", result)

نمونه کد ۲ — شمارش نمره‌ها و محاسبه میانگین

scores = [18, 15.5, 20, 17, 16]
average = sum(scores) / len(scores)
passed = [score for score in scores if score >= 10]

print(f"میانگین کلاس: {average:.2f}")
print(f"تعداد قبول‌شده‌ها: {len(passed)}")

نمونه کد ۳ — ذخیره نام‌ها در فایل

name = input("نام هنرجو: ")

with open("students.txt", "a", encoding="utf-8") as file:
    file.write(name + "\\n")

print("نام هنرجو ذخیره شد.")
تمرین پیشنهادی: یک برنامه دفترچه نمرات بساز که نام و نمره هنرجوها را بگیرد، میانگین را حساب کند، افراد قبول‌شده را نشان دهد و اطلاعات را در فایل ذخیره کند. بعد نسخه دوم را طوری توسعه بده که اطلاعات را از فایل بخواند و امکان جست‌وجوی نام داشته باشد.

منابع فارسی و ایرانی برای یادگیری پایتون

  • پای‌دان — آموزش موضوعی فارسی با مثال‌هایی که در مرورگر اجرا می‌شوند؛ مناسب تمرین قدم‌به‌قدم.
  • پایتون به پارسی — کتاب آنلاین فارسی و متن‌باز برای یادگیری ساختارمند.
  • کوئرا — تمرین و مسئله‌های برنامه‌نویسی برای تقویت حل مسئله؛ بخشی از امکانات و محتوا ممکن است شرایط دسترسی متفاوت داشته باشد.
  • مکتب‌خونه — دوره‌های فارسی پایتون؛ رایگان یا پولی بودن هر دوره را در صفحه همان دوره بررسی کن.
  • فرادرس — آموزش‌های فارسی متنوع و پروژه‌محور؛ پیش از انتخاب، سرفصل و پیش‌نمایش دوره را ببین.
  • مخزن منابع رایگان برنامه‌نویسی فارسی — فهرستی اجتماعی از کتاب‌ها و ویدیوهای فارسی؛ کیفیت و به‌روز بودن هر مورد را جداگانه ارزیابی کن.

پیشنهاد: یک منبع اصلی انتخاب کن و تا پایان مبانی همان را ادامه بده؛ هم‌زمان چند دوره را شروع نکن. برای مرجع نهایی و بررسی جزئیات زبان، آموزش رسمی Python را هم نگه دار.

THE POWER OF LINUX

لینوکس؛ جایی که برنامه‌نویسی به دنیای واقعی وصل می‌شود

لینوکس فقط یک سیستم‌عامل جایگزین ویندوز نیست؛ ابزار مهم توسعه‌دهنده‌ها، مدیران سرور و متخصصان شبکه و امنیت است.

لینوکس چیست؟
لینوکس خانواده‌ای از سیستم‌عامل‌های متن‌باز است که توزیع‌های مختلفی مثل Ubuntu، Debian و Fedora دارد. بسیاری از سرورها، زیرساخت‌های ابری، تجهیزات شبکه و محیط‌های توسعه از لینوکس استفاده می‌کنند. برای شروع، Ubuntu انتخابی ساده و مستندات‌دار است؛ لازم نیست از همان روز اول سراغ Kali بروی.

آزمایشگاه و یادگیری

ساخت ماشین مجازی، آزمایش تنظیمات، تمرین خط فرمان و یادگیری بدون دست‌کاری سیستم اصلی.

چند دستور ابتدایی لینوکس

pwd                 # نمایش مسیر فعلی
ls -la              # فهرست فایل‌ها، همراه جزئیات
cd Documents        # ورود به یک پوشه
mkdir practice      # ساخت پوشه
cp a.txt b.txt      # کپی فایل
mv b.txt old.txt    # تغییر نام یا جابه‌جایی
cat old.txt         # نمایش محتوای فایل
whoami              # نام کاربر فعلی
ip a                # نمایش رابط‌ها و نشانی‌های شبکه
sudo apt update     # به‌روزرسانی فهرست بسته‌ها در Ubuntu/Debian
چطور تمرین کنی؟
ابتدا Ubuntu را در ماشین مجازی (VirtualBox) نصب کن یا از WSL در ویندوز استفاده کن. با فایل‌ها، پوشه‌ها، کاربران، مجوزها، پردازش‌ها، نصب بسته‌ها و ترمینال تمرین کن. هر دستور را بفهم؛ دستورهای ناشناس را کورکورانه با دسترسی مدیر اجرا نکن.

منابع فارسی لینوکس

  • کتابخانه لینوکس — کتاب‌های رایگان فارسی درباره لینوکس، خط فرمان و متن‌باز.
  • لینوکس‌پارسی — مرجع فارسی در حال توسعه برای توزیع‌ها و مباحث لینوکس؛ مطالب را با مستندات رسمی تطبیق بده.
  • Linux Guide در GitHub — یادداشت‌ها و تمرین‌های فارسی از نصب و خط فرمان تا شبکه و اسکریپت‌نویسی.
  • راهنمای منابع رایگان لینوکس — معرفی مسیر و منابع تمرین، از جمله دوره‌های فارسی جادی.
  • آموزش خط فرمان اوبونتو — مرجع رسمی انگلیسی برای تکمیل آموزش.
CYBERSECURITY IS A DISCIPLINE

می‌خواهی هکر یا متخصص امنیت شوی؟ مسیر خیلی عمیق‌تری لازم داری

چند سؤال مهم

آیا باید از روز اول چند زبان برنامه‌نویسی یاد بگیرم؟

خیر. ابتدا یک زبان برای یادگیری منطق انتخاب کن. در این نقشه Python نقش زبان شروع را دارد؛ بعد از شناخت علاقه، زبان و ابزار تخصصی را انتخاب می‌کنی.

آیا با ۱۵ ماه حتماً استخدام می‌شوم؟

خیر؛ زمان‌بندی فقط یک هدف آموزشی است. استخدام به کیفیت مهارت، نمونه‌کار، توانایی حل مسئله، شرایط بازار و عملکرد در مصاحبه بستگی دارد.

اگر در یک مرحله عقب افتادم چه کنم؟

عجله نکن. به تمرین‌های ساده‌تر برگرد، خطاها را بررسی کن و وقتی توانستی بدون راهنمای قدم‌به‌قدم پروژه را انجام بدهی، ادامه بده.

آیا استفاده از هوش مصنوعی در یادگیری درست است؟

بله، برای توضیح مفاهیم، راهنمایی و بررسی خطا. اما اول خودت تلاش کن و از هوش مصنوعی بخواه راهنمایی‌ات کند، نه اینکه تمام تکلیف را به‌جایت انجام دهد.
